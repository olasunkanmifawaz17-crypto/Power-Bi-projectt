# Data Job dashboard project

This Power BI project analyzes a dataset of data-related job postings to explore hiring trends, job roles, locations, required skills, experience levels, and salary information. The interactive dashboard provides insights into the data job market, helping identify in-demand skills, popular roles, and employment opportunities across different locations and categories.
## Dashboard Features
The dashboard features multiple interactive pages designed for easy navigation and data exploration. It includes interactive buttons, slicers, Cards, charts, tables, bookmark and other visualizations. Users can filter and explore job posting data dynamically, while the interactive elements provide a clear and engaging way to navigate between different sections of the dashboard.


![Dashboard Image](/Dashboard%20Preview.png)

## The dashboard has four pages 👇

1. Home
2. Salary Insight
3. Job Types and Details
4. Job Posting Country and Dat


### Home
Homepage: 
Data Job Salary Insight:
The homepage provides an overview of salary insights across different data-related job roles. It presents the median yearly salary through KPI cards, a salary comparison gauge, and an interactive table showing job titles, median salaries, and salary ratings. Navigation buttons also allow users to explore other sections of the dashboard.

![Homepage Image](/Home.png)

### Salary Insight
Salary Insight Page:
This page provides a detailed comparison of salaries across different data-related job roles. It includes interactive charts showing the highest-paying positions by day, month, and hourly rates, alongside job-specific salary comparisons. Interactive job-role buttons and selection controls allow users to filter the visualizations and explore salary insights based on their chosen roles.
![Salary Insight Image](/Salary%20Insight.png)

### Job Types and Details
Job Types and Details Page:
This page provides an overview of key characteristics of data job postings. It uses interactive donut charts to analyze health insurance availability, work-from-home options, and salary rates, alongside a pie chart showing degree requirements. A treemap further illustrates the distribution of different job schedule types.
![Job Types and Details Image](/Job%20Types%20and%20Details.png)

### Job Posting Country and Date
Job Posting Country and Date Page:
This page explores the geographical and temporal distribution of data job postings. It includes a bar chart highlighting countries with the highest number of job postings, a line chart showing posting trends over time, and a waterfall chart illustrating monthly changes in posting counts. An interactive slicer allows users to filter the analysis by different data job types.
![Job Posting Country and Date Image](/Job%20Posting%20Country%20and%20Date.png)
### Tools & Skills
**Power BI** — Dashboard development and interactive visualizations

**Power Query** — Data cleaning and transformation

**DAX** — Measures and calculated metrics

**Data Visualization** — Charts, cards, tables, slicers, and interactive navigation

**Data Analysis** — Salary, job type, location, and posting-trend analysis

### Project Outcome
This project demonstrates the use of Power BI to transform raw job posting data into an interactive dashboard that makes salary patterns, job characteristics, geographical distribution, and posting trends easier to explore and understand.
